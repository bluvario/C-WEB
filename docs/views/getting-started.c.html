Getting started

You need a C11 compiler, make, ar, and zlib. OpenSSL is optional and enables HTTPS.

Build the framework

make

That produces two things:

  • build/libcweb.a — the whole framework as one static library.
  • build/cweb — the command-line tool that builds and serves apps.

Run the test suite once, it is fast:

make test

Scaffold your first app

./build/cweb new hello
cd hello

This creates a runnable skeleton:

hello/
  views/
    index.c.html          the home page (answers GET and POST)
    404.c.html            custom not-found page
    layout.c.html         document shell wrapping every page
    partials/footer.c.html  a fragment only pages render
  static/
    style.css             served from the /* mount

Serve it

../build/cweb serve views 8080 . static

Point a browser at http://localhost:8080. Now edit views/index.c.html and refresh — that is the whole loop. The template is recompiled on every request, so there is no build step while you work on a page.

Note: cweb serve runs the generated server binary. The compile happens once at startup (or on each change in --watch mode), not per page hit.

Watch mode

Add --watch and the tool rebuilds and restarts the server whenever a template or static file changes, so a long-running app picks up your edits without you touching anything:

../build/cweb serve --watch views 8080 . static

Build a production binary

When you are done editing, compile the app into a deployable binary. The layout, pages and partials are compiled into it — nothing needs to be shipped except the binary (plus your static dir, if you keep it separate):

../build/cweb build views out . static
./out/server --port 8080 --db app.db --secure

The generated server accepts a long list of flags; see The cweb CLI for every one of them.

The example apps

Two working apps ship in examples/. Build them and read them — they double as documentation:

make examples
  • examples/login — session cookies, a form, a logout route, and a tiny auth flow you can copy.
  • examples/notes — a real notes app: layout wrapper, a --db store, form handling, and static assets.
